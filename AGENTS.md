# AGENTS.md

## Cursor Cloud specific instructions

### Project overview

AdGuard WireGuard Hotspot Bridge — a single-module Android app (`:app`) that bridges a WireGuard VPN tunnel to Wi-Fi hotspot. UI is in Russian. Built with Kotlin + Jetpack Compose + Room + WireGuard tunnel library.

### Build environment

- **JDK 17** is required (`JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64`). The VM also has JDK 21 installed; Gradle will use whichever `JAVA_HOME` points to.
- **Android SDK** is at `/opt/android-sdk` (platform 35, build-tools 35.0.0). `local.properties` with `sdk.dir` is generated by the update script.
- Environment variables (`JAVA_HOME`, `ANDROID_SDK_ROOT`, `ANDROID_HOME`) are set in `~/.bashrc`.

### Key commands

| Task | Command |
|---|---|
| Build debug APK | `./gradlew :app:assembleDebug` |
| Run lint | `./gradlew :app:lintDebug` |
| Kotlin compile only | `./gradlew :app:compileDebugKotlin` |

### Gotchas

- **No automated tests exist** — there are no `src/test/` or `src/androidTest/` directories. `./gradlew test` will succeed vacuously.
- **Lint has 2 pre-existing errors** (ForegroundServiceType) and 45 warnings. `lintDebug` will exit non-zero due to these errors.
- The app requires a physical Android device or emulator for runtime testing (VPN + hotspot features). It cannot be meaningfully run inside this cloud VM.
- `local.properties` is gitignored; the update script regenerates it on each startup.
- Gradle downloads its distribution on first run (~1 min). Subsequent builds use the cached distribution.
